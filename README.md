# Python Tools Collection

A lightweight, modular collection of developer utilities built with Python 3.11 and Tkinter. Designed for high performance, minimal dependencies, and rapid extensibility.

### Features

* **MD5 Checksum**: Instant MD5 hash generation for text strings.
* **Base64 Encoder/Decoder**: URL-safe Base64 processing with auto-padding support, fully compatible with JWT payload extraction.

### Requirements

* Python 3.11+
* No external dependencies required (Standard Library only).

### Quick Start

Clone the repository and execute the main entry point:

```bash
git clone <your_repository_url>
cd PythonTools
python main.py
